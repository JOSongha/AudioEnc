\section{Projector Architecture}
\label{app:projector}

The projector is a four-layer causal Llama decoder adapter~\cite{Ll23} with hidden size $512$, $8$ attention heads, and a feed-forward dimension of $2048$.
It is preceded by an input linear projection $\mathbb{R}^{d_{\text{enc}}} \!\to\! \mathbb{R}^{512}$ and followed by an output linear projection $\mathbb{R}^{512} \!\to\! \mathbb{R}^{2560}$, where $d_{\text{enc}}$ is the encoder's latent dimensionality listed in Table~\ref{tab:encoders}.
Each decoder layer uses pre-norm RMSNorm~\cite{ZL20}, SwiGLU~\cite{Sh20}, rotary position encoding~\cite{SP23}, and FlashAttention-2 causal attention~\cite{Dao23}.
The four decoder layers, the final RMSNorm, and the output projection are shared across all encoders and contribute $18{,}092{,}544$ parameters.
Only the $d_{\text{enc}} \!\times\! 512$ input projection varies with the choice of encoder, so the total projector size is within $\pm 2\%$ of $18.2$M across all configurations.

\section{Training Details}
\label{app:training}

\paragraph{Sequence packing.}
We pack multiple utterances into a single length-$3584$ training sequence using neat packing~\cite{Kundu24,Kr23}.
Utterances are placed greedily into bins using a first-fit-decreasing knapsack, and each bin is padded at the tail with the text pad token (not the audio placeholder) to reach $3584$ tokens.
Cross-sample attention within a bin is prevented by encoding per-sample identifiers into the attention mask: the $k$-th utterance in a bin receives mask value $k+1$, padding receives $0$.
When using the FlashAttention-2 varlen kernel we additionally strip all padding, concatenate the remaining tokens, and supply \texttt{cu\_seqlens} markers~\cite{Dao23}; the label of the first token of each utterance is overwritten with the ignore-index to prevent the causal-shift loss from crossing utterance boundaries.

\paragraph{Optimization and system setup.}
We train for $100{,}000$ steps with bfloat16 mixed precision~\cite{Ka20}, which amounts to approximately $1.8$ epochs over the training set.
The optimizer is AdamW~\cite{LH19} instantiated via the DeepSpeed FusedAdam kernel~\cite{DS20}, with a peak learning rate of $2 \times 10^{-4}$, weight decay $0.01$, a linear warm-up of $1000$ steps, and a warm-up, stable, decay schedule~\cite{HF23}.
Data-parallel training is performed across $8$ GPUs per node with DeepSpeed ZeRO stage~2~\cite{Ra20,DS20}, a per-device batch of $3$ packed sequences, and gradient checkpointing.
We additionally enable the Liger Kernel~\cite{Ho24} for fused SwiGLU, RMSNorm, and RoPE operations, and set \texttt{expandable\_segments=True} in the CUDA caching allocator to mitigate fragmentation under long packed sequences.
